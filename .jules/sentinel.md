## 2026-05-20 - [HTTP Header Injection in File Downloads]
**Vulnerability:** The POA&M CSV download endpoint dynamically set the `Content-Disposition` header filename using the user-provided `system_name` parameter without sanitization (only replaced spaces with underscores). This could allow an attacker to inject CRLF (`\r\n`) sequences or double quotes to manipulate HTTP headers or file paths.
**Learning:** Even internal or seemingly benign string inputs like "system names" must be rigorously sanitized before being interpolated into HTTP response headers, as many web frameworks do not automatically sanitize header values.
**Prevention:** Always use regex sanitization (e.g., `re.sub(r'[^a-zA-Z0-9_\-]', '_', user_input)`) to strictly whitelist characters when user input must be included in a header like `Content-Disposition`.
